# Demo How-To guides (not client content)

The client's knowledge base lists guide titles only; the full articles are in their Confluence space
(SUP-KB), which was not shared. These short guides were written for the demo so the agent can answer
How-To questions end to end. The menu paths are illustrative, not Payce's real screens.

They are imported at worker start only when `DEMO_GUIDES=on` (the default in the demo region), only
for guides that have no imported article yet, and they are replaced as soon as the real article is
imported on the Knowledge page. Statutory figures (PF, TDS, PT, gratuity) are never written here:
they come only from the dated rule table.
